## Donovan Crowley

### Notable Projects
* **[Web Scraper](https://github.com/donovan-crowley/WebScraper)** Python pathfinding agent using Hugging Face Sentence Transformers, cosine similarity, and A* Search to find the shortest path between two unrelated Wikipedia pages.
* **[Object Tracker](https://github.com/donovan-crowley/ComputerVis)** Real-time centroid object tracker with adaptive HSV threshold training and state-driven architecture
* **[Photo Print](https://github.com/donovan-crowley/PhotoPrint)** Photo collage generator using K-means algorithm to vectorize and separate images into two distinct buckets and outline a particular image/pattern
* **[Portfolio Website V2](https://github.com/donovan-crowley/Portfolio-V2)** Updated portfolio website using React.js, Vite, and Bootstrap.
* **[Original Portfolio Website](https://github.com/donovan-crowley/donovan-crowley.github.io)** Built with HTML, CSS, and JavaScript.
* **[Care Without Barriers Nonprofit](https://github.com/donovan-crowley/Care-Without-Barriers)** Nonprofit that provides free complete blood count tests, lipid panels, and metabolic panel screenings to uninsured and underserved individuals; Built with React.js, Vite, and Bootstrap.
